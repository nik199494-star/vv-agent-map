# ВВ Агент | Карта потребности

Статическая карта читает два опубликованных файла и сохраняет последний проверенный снимок в браузере. [Карта для агентов](https://nik199494-star.github.io/vv-agent-map/)

В рабочей ветке добавлен путь от проверки HRM FULL и исправления справочника до верификации сайта. Используется существующий обработчик принятия снимка.

- [Аудит архитектуры и интеграций](docs/audit.md)
- [Настройка, секреты и приёмка](docs/installation.md)
- [Регламент менеджера после запуска](docs/manager-guide.md)
- [Испытательный контур и настройка preview](docs/preview.md)
- [Проверка адресов 21 ТТ](docs/geography-review.md)

Для проверки нужен Node.js 22 или новее. Установка зависимостей не требуется.

    node --test
    node build.mjs

Папка dist содержит только файлы карты. Код Apps Script, закрытые выгрузки, пароли и отчёты хранятся отдельно.

Штатный генератор оставлен для технической поддержки.

    node scripts/publish-demand.mjs путь-к-агентскому-файлу.csv
    node scripts/prepare-locations.mjs

Первая команда обновляет локальный demand.json. Вторая формирует очередь проверки координат. GitHub Actions использует тот же генератор с дополнительной сверкой паспорта и публикации.
