# Обновление потребности для менеджера

Регламент применяется после утверждения и установки новой команды. До этого действует прежняя производственная инструкция.

1. Скачайте свежую FULL-выгрузку HRM. Вставьте её в HRM FULL с исходными заголовками. Если выгрузка содержит дату формирования, сохраните её в ячейке, указанной при настройке.
2. Нажмите «ВВ Потребность → Принять снимок и обновить карту».
3. Следите за статусом в «Автодиагностике». «Снимок принят» означает завершение записи в HISTORY. «Карта обновлена» появляется после проверки общедоступных файлов.
4. При блокировке откройте последнее критическое замечание, уточните исходные данные и повторите команду. При ошибке GitHub повторная команда использует уже принятый снимок.
5. После статуса «Карта обновлена» проверьте дату HRM и выборочную ТТ. При необходимости сообщите агентам об обновлении по действующему регламенту. [Карта для агентов](https://nik199494-star.github.io/vv-agent-map/)

## Если в витрине появился новый адрес

1. Найдите ID и новый адрес в «Геоконтроле».
2. После сверки укажите широту, долготу, публичную ссылку на источник, дату и статус «Подтверждено».
3. Если выпуск без маркера согласован, установите «Принят без маркера». ТТ останется в списке. Предыдущая привязка сохранится в геоконтроле.
4. Повторите команду обновления. Если автоправка справочника оказалась ошибочной, введите идентификатор запуска из журнала через пункт «Откатить автоисправления».
